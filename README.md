# my-website

A single-page website for **AI Fans**, a concept for an intelligent winter road-safety system. Fans mounted in a car's front grille blow warm air and spray a urea solution to melt ice on the road. Sensors and AI decide when to activate the system, so the solution is used only when needed.

## Files

- `AIFANS.html`: the main page (content, components, location, working hours).
- `style.css`: styles for the page, including responsive layout and the footer.
- `image 1.png` to `image 6.png`: photos used on the page.
- `certificates/course-completion-certificate.png`: certificate of completion for the Introduction to Entrepreneurship course.

## Running locally

Open `AIFANS.html` in a web browser. Keep it in the same folder as `style.css` and the images so they load correctly.
